S10-1 图形模式

Mode13h：给屏幕开"画图模式"

VGA 标准 320x200×256 色图形模式。内核直接写 0xA0000 帧缓冲（一个字节一个像素），画点/画线/填色都从这里开始。gui_pixel / fill / rect 三个基础画笔。
  • vga_set_mode13h()：寄存器序列切换
  • vga_set_mode03()：退出回 80x25 文本
  • 帧缓冲 16 页映射（0xA0000-0xAFFFF）
实测通过 · 0 页错误
S10-2 窗口管理器

窗口：桌面上的小天地

最多 6 个窗口，每个有标题栏（9 像素高）。4 种类型：CLOCK（时钟）、SYSINFO（系统信息）、DEMO（动画）、WINPP（Logo）。底部帮助栏显示快捷键。
  • gw_add / gw_activate / gw_close_active
  • GUI 主循环每 3 ticks 重绘动画
  • 深蓝渐变桌面 + 8x8 鼠标箭头光标
实测通过 · 激活/新建/关闭全命中
S10-3 PS/2 鼠标

鼠标：桌面上的指针

8042 辅助设备（IRQ12）驱动：初始化（0xA8 启用 → 0xD4 写命令 → 0xF4 使能报告）、3 字节数据包解析（flags/dx/dy）、坐标限幅 320x200、左右键状态。
  • mouse_init()：PS/2 enabled 串口日志
  • mouse_handle_irq()：bit5 防吞键盘
  • 作为字符设备注册（major 4, irq 12）
驱动完成 · Bochs 初始化验证

shell 命令：怎么进入图形界面

终端输入 gui 回车，内核切到 320x200 图形模式并启动窗口管理器。
输入作用
gui进入图形模式（Mode13h）+ 启动窗口管理器（默认 4 个窗口）
qGUI 内退出：切回 80x25 文本模式，回到 shell
1 - 5GUI 内激活对应编号窗口（1=CLOCK 2=SYSINFO 3=DEMO 4=WINPP ...）
nGUI 内新建一个 WIN 窗口（最多 6 个）
xGUI 内关闭当前激活窗口
gui 进图形1-5 切窗口n 新窗口x 关窗口q 回文本

设计修正（三个真机 Bug，全部定位并修复）

Bug 1：鼠标初始化命令写错 0x60 → 关 A20 破坏键盘

mouse.c 用 outb(0x64, 0x60) 想"把下一字节发给鼠标"，但 0x60 是写输出端口命令——0xF4（bit1=0）被写到 8042 输出端口，把 A20 关闭，内核访问 >1MB 内存全部错乱，表现为键盘注入全部失效。修复：改成 0xD4（下一字节发给辅助设备/鼠标）。禁用鼠标对照实验实锤：无鼠标版键盘立即恢复。

Bug 2：分页只映射 1 页帧缓冲 → 0xA1000 页错误

第一版只映射 0xA0000 一页，GUI 写满 64KB 帧缓冲（320x200=64000 字节）立刻在 0xA1000 触发 #PF。修复：整段映射 16 页（0xA0000-0xAFFFF）。修复后 0 页错误，深蓝桌面正常绘制。

Bug 3：serial_getc 空返回 -1 → GUI 日志刷屏

GUI 主循环 if (!c) c = serial_getc(); if (c) ...，串口无数据时返回 -1（非 0）被当真按键，每 tick 刷一条 [gui] key 'ÿ'。修复：空返回 0（与 keyboard_poll 语义一致）。修复后日志干净。
