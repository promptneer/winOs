2. 机器实测（Bochs 串口取证）

[vt] init: 3 virtual terminals (VT1..VT3), active=VT1 [vt] switch -> VT2 (cwd=/) ← vt 2 命令切换成功 [vt] cmd switch -> VT2 mkdir ok: /docs ← 在 VT2 里建目录 cd ok: /docs ← 在 VT2 里 cd（提示符变 /docs#） [vt] list: active=VT2 ← VT2 的终端表

屏幕转储（VT2 里执行 vt 的表格）：

id name status cwd msgs 1 VT1 idle / 0 2 VT2 ACTIVE /docs 0 ← 只有 VT2 的目录变了 3 VT3 idle / 0 root@kernel:/docs# pwd /docs ← VT2 里 pwd 确认
