B · 管道 pipe（S5-1）

匿名管道：写端写、读端读，环形缓冲。user7 创建一次管道，循环写读回。

T-03pipe：启动管道演示进程
pipe
VGA 屏幕（应显示）
created pipe-demo proc: pid 1
串口 COM1（应出现）
[pipe] demo proc pid 1
[ipc] pipe created: read-fd=0 write-fd=1
判据pipe created 必须只出现 1 次（管道是持久对象，只创建一次）；read-fd=0 write-fd=1（从 0 号槽开始）。

# ... 每轮：写 "Hello Pipe!" 进管道 -> 从读端读回 -> 串口打印，循环不断

D · 消息队列 mq（S5-3）

信箱传信：每条消息有长度边界。user9 循环投 3 条不同长度消息、收 3 条打印。

T-09mq：启动消息队列演示进程
mq
VGA 屏幕（应显示）
created mq-demo proc: pid 1
串口 COM1（应出现）
[mq] demo proc pid 1
[mq] send len=2 total=1
[mq] send len=5 total=2
[mq] send len=7 total=3
判据连续投 3 条：2 字节（"AB"）、5 字节（"msg12"）、7 字节（"msg-789"），total 从 1 涨到 3 —— 三种不同长度的消息入队成功。
T-10ps + 闭环验证：user9 在表里，消息收发在循环
ps
VGA 屏幕（应显示）
PID  STATE  NAME    CODE     TICKS
 1   ready  user9   660000   ...
 0   ready  shell   ...      ...
串口 COM1（应持续出现）
[mq] recv len=2 total=2
[pid1] AB
[mq] recv len=5 total=1
[pid1] msg12
[mq] recv len=7 total=0
[pid1] msg-789
# ... 循环：投 3 条 -> 收 3 条打印，长度一一对应
判据① ps 表里有 user9，CODE=660000；② 串口循环：recv len=2 → AB、recv len=5 → msg12、recv len=7 → msg-789，每条收完 total 递减 —— 收发一一对应，消息内容与长度都正确。
