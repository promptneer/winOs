阶段：S16 硬盘驱动（ATA PIO） ｜ 2026-10-13 ｜ 实测全绿，源码已提交推送

一句话总结

S1-S15 的内核一直活在"内存和软盘"里，S16 让内核第一次接上真正的硬盘：通过 ATA PIO 接口读出硬盘身份证（型号/容量）、读扇区、写扇区，并自动做"写进去再读出来比对"的回验。这是 S17 磁盘文件系统（文件真存进硬盘、断电不丢）的地基。

本阶段完成内容

#模块类型说明
1src/ata.h + ata.c新增ATA PIO 硬盘驱动：主通道 0x1F0-0x1F7（数据/扇区数/LBA 低中高/驱动器/状态命令寄存器）；ata_init 软复位探测 + IDENTIFY（0xEC）读 256 个 16 位字，解析型号（word 27-46）、序列号（word 10-19）、CHS、容量；ata_read_sector / ata_write_sector 用 LBA28 寻址 + PIO 读（0x20）/写（0x30），等待 BSY/DRQ 状态位。
2src/shell.c修改新增 cmd_hd 命令：hd info（显示 IDENTIFY 参数）、hd read <lba>（十六进制 dump 前 64 字节）、hd write <lba> <text>（写前 64 字节其余补零）、hd test（写签名→读回→逐字节比对 PASS）；命令表 + help 文案。
3src/kernel.c修改初始化序列新增 [11f] ata hdd → ata_init()，开机自动探测硬盘。
4bochsrc.txt修改新增 ata0（0x1F0/0x3F0/IRQ14）+ ata0-master（10MB 虚拟硬盘，20 cyl × 16 heads × 63 spt = 20160 扇区）。
5hd.img + _mk_hdimg.py新增10MB 虚拟硬盘镜像（20160 扇区），扇区 0 预写 WINPP-HD-IMAGE-V1 签名 + MBR 55AA，便于实测 hd read 0。
6构建产物更新kernel.bin 297 sectors（约 148 KB），floppy.img 可启动镜像，构建 0 error（仅历史遗留 1 个 unused-function warning）。

Bochs 机器实测取证（serial.out 关键行）

[ata] IDENTIFY ok: 20 cyl 16 head 63 spt, 20160 sectors (9 MB)   ← 开机识别硬盘 ✓
[hd] rw test PASS lba=200 sig=S16-DISK-RW-TEST                     ← 写读回验 ✓

Windows 侧自动化断言（_s16_test.py）：
  HD INFO MODEL      : True   ← hd info 显示型号
  HD READ0 SIG       : True   ← hd read 0 读到 WINPP-HD-IMAGE-V1 签名
  HD WRITE           : True   ← hd write 0 hello-s16 → wrote 9 bytes
  HD READ BACK       : True   ← 再读 LBA 0 看到 68 65 6c 6c 6f（hello-s16）
  HD TEST PASS       : True   ← hd test 写 LBA 200 签名串并逐字节比对通过

实现要点与已知限制（诚实说明）

项说明
PIO 模式（无 IRQ/DMA）教学级实现：轮询状态寄存器（BSY/DRQ）而非中断或 DMA，一次读写一个扇区（512B）。真机也可用，只是速度慢。
LBA28 寻址支持最大 128GB 的盘（28 位 LBA）；Bochs 这个 10MB 测试盘绰绰有余。未实现 LBA48。
单盘主通道只探测主通道主盘（ata0-master），未做从盘/第二通道枚举。
hd write 只写 64 字节命令参数只取前 64 字节文本，其余 448 字节补零——教学演示足够，S17 磁盘文件系统会用完整 512 字节组织扇区。
显示容量 9 MB20160 扇区 × 512B = 10,321,920B ≈ 9.84MiB，内核按"扇区数/2048"取整显示为 9 MB（诚实口径）。

下一阶段预告：S17 磁盘文件系统
