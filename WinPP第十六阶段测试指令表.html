阶段主题：硬盘驱动（ATA PIO）—— 认识硬盘、读扇区、写扇区 ｜ 逐项实测勾选，全部通过后才能进入 S17

本阶段是什么（一句话）

S16 让你的内核第一次"摸到真正的硬盘"：通过 ATA PIO 接口读取硬盘身份信息（型号/容量），读扇区（512 字节一块）和写扇区，并做读写回验。S1-S15 的文件系统是内存里模拟的（断电就没），S16 打地基，S17 才能把文件真正存进硬盘。

测试方法（先读这一段）

第 1 步：双击 D:\WinPP\启动WinPP内核.bat 启动内核（本次启动会自动探测硬盘并显示 [ata] IDENTIFY ok）。

第 2 步：在 WinPP shell 里输入 hd 开头的命令，回车执行。

第 3 步：每测完一项，点该项右侧的 ☐ 勾选框打勾。勾选会保存在本机浏览器（localStorage）。

提示：hd 命令的完整用法是 hd info|read <lba>|write <lba> <text>|test。LBA 就是"扇区编号"，0 是第一块扇区。写扇区会真实改到 hd.img 文件，写坏了重跑 python D:\WinPP\winpp-os\_mk_hdimg.py 就能还原空盘。

失败排查速查

现象原因与处理
开机没有 [ata] IDENTIFY ok确认 bochsrc.txt 里有 ata0 和 ata0-master 两行配置（本次已加）；确认 hd.img 存在（D:\WinPP\winpp-os\hd.img，10MB）。删除 hd.img 后重新 python D:\WinPP\winpp-os\_mk_hdimg.py 生成。
hd info 显示 0 容量Bochs 的 IDENTIFY 不报 LBA28 总数时内核自动用 CHS 推算（20 cyl × 16 × 63 = 20160 扇区 ≈ 9MB）。显示 0 说明探测失败，重启内核再试。
hd read 0 全是 00说明扇区 0 被清空过（比如之前 write 过别的内容）。用 python D:\WinPP\winpp-os\_mk_hdimg.py 重建空盘（含 WINPP-HD-IMAGE-V1 签名）再看。
hd write 后 hd read 看不到内容确认 write 命令格式：hd write 0 hello（只写前 64 字节，其余补零）；read 0 看前 64 字节十六进制：hello 对应 68 65 6c 6c 6f。
hd test 显示 MISMATCH读写链路有问题：先确认 [ata] IDENTIFY ok；重启内核重试；仍失败把屏幕截图给我。
