二、小白版一句话：这阶段做了什么

  • 统一 Socket：以前 UDP 是 UDP、TCP 是 TCP，两套命令；现在收成一个"插座"概念——open / connect / send / recv / close / list 一套命令通吃 UDP 和 TCP。
  • DNS 客户端：内核自己会"查号"了——输入域名（如 www.baidu.com），它自己发 DNS 查询包、收应答、跳过 CNAME 别名、找到真正的 IP 地址，不用再手填 183.2.x.x。
  • 意义：这是"上网能力"从玩具变成真家伙的收尾——既有传输层（UDP/TCP），又有应用层入口（DNS），下一步就能让内核"按域名找服务器、连上去收发数据"。

三、已知限制（测试前先看，避免误判）

  • Bochs slirp 不转发"内核主动发出的 UDP"到宿主：第 6 项内核侧 rc=0 即"已发出"（帧级可取证），Windows 收不到是模拟器限制；真机（U 盘启动）无此限制。
  • UDP 接收缓冲 256 字节：超过会被截断（DNS 响应通常够用，完整大包接收留给后续阶段）。
  • 一次只允许一个活跃 socket：open 新 socket 前必须 sock close（内核会提示 close current socket first）。
  • dns 查询时内核忙等约 6 秒，期间不响应新命令，属正常。
