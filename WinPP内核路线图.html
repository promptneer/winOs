当前位置：S1–S11 全部完成并实机取证（引导 → 分页 → 用户态 → 地址空间/fork/exec/fs → IPC → 目录路径 → 设备驱动 → 用户与权限 → 信号同步 → 图形界面窗口系统 → 网络协议栈），推送 GitHub。下一战场 S12 多终端会话系统。每个阶段完成后机器实测（Bochs 串口 + 截图双通道）。

S7 · 设备驱动

把键盘、定时器、串口这些"外设"从散落的代码整理成正式的设备驱动层（device table + 统一接口），中断处理按设备分发。

S8 · 用户与权限

新增 root 用户（UID 0）、普通用户、文件属主与 rwx 权限位；root 提示符 #、普通用户 $。为 S10 GUI 登录打地基。

S9 · 信号与同步

sleep / wait / 信号量 / 互斥锁，让多个进程学会"排队等资源"，不再抢作一团。
