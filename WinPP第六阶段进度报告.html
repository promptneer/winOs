第六阶段：文件系统增强（目录 / 路径）

一句话意义：第四阶段的文件系统是"一张只有文件的桌子"；第六阶段升级成"有文件夹、有路径的柜子"——能 mkdir 建目录、能用 dir/file.txt 找文件、能 cd/ls/pwd 在柜子里走动。全部 Bochs 实机 + 串口 + 截图验证通过。

三大件：是什么、怎么用

大白话对照 —— 让文件系统从"平铺一堆文件"变成"有结构的柜子"。
S6-1 目录 mkdir

文件夹

在柜子里加一个隔层：目录项（type=5）占一个槽，能装下属文件。
  • syscall 13 mkdir(path) 创建目录
  • 父目录必须存在；已存在幂等返回 0
  • 内存盘 16 槽，目录与文件共用
实测通过 · /docs + /docs/docs2
S6-2 路径解析

带斜杠的地址

文件有了完整地址：/docs/a.txt；相对路径 b.txt 自动拼成 /docs/b.txt。
  • fs_resolve 拼接 cwd + 规范化（去尾斜杠）
  • open/write/read 全程走解析后的绝对路径
  • 创建文件时检查父目录是目录
实测通过 · 绝对+相对双通道
S6-3 shell 增强

在柜子里走动

shell 变成真正的文件管理器：提示符实时显示当前目录。
  • mkdir / cd / pwd / ls 四条新命令
  • 提示符 winpp@kernel:/docs$
  • ls 列目录：目录带 /，文件带大小
实测通过 · 提示符随 cd 变化

新增系统调用（int 0x80）

至此 WinPP 开放 0-14 共 15 个系统调用。
编号调用参数说明
13mkdirpath创建目录（支持相对/绝对路径），已存在返回 0
14chdirpath切换内核当前目录，目标必须是目录

串口铁证（COM1）

Bochs 2.8 实机，键盘注入完整目录操作序列，全程 0 页错误。
S6-1 目录与路径PAGE_FAULT = 0
[fs] mkdir '/docs' fd=0
[fs] mkdir '/docs/docs2' fd=1       # 相对路径建目录：cwd=/docs + docs2
[fs] chdir '/docs'                    # shell cd 生效
[fs] mkdir '/docs' (exists)          # 幂等：重复创建返回 0
S6-2 路径解析（fs2 演示 user10）PAGE_FAULT = 0
[fs] open created '/docs/a.txt' fd=1   # 绝对路径创建

[fs] open created '/docs/b.txt' fd=2   # 相对路径 "b.txt" -> /docs/b.txt！
[fs] open '/docs/b.txt' fd=2 (exist)
# ... 循环 800 次：写 "Sub File!" 进 b.txt -> 读回 -> 串口打印

设计修正（1 处）

BUG-S6-01：ls 根目录标题显示 "//:"

fs_ls 把解析结果 "/" 直接拼上 "/" 输出，根目录标题变成双斜杠。修正：path=="/" 时标题输出 "/:"，否则输出 "path/:"。复测：[ls] /: 正确。
